# Michal Milke - Professional Profile

Professional portfolio website for Michal Milke, founder of ReviewAI.

Live site:
https://desdem0n.github.io/profile/

## Local Development

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3000.

## Build

```bash
npm run build
```

The project is configured for static export and GitHub Pages deployment.
